# Supply Chain Performance Analytics Dashboard

## Project Overview
Designed and developed an end-to-end Supply Chain Performance Analytics Dashboard in Power BI to transform raw logistics data into actionable business insights for operational decision-making.

## Business Objectives
- Monitor shipment performance
- Analyze warehouse capacity
- Track logistics efficiency
- Identify operational bottlenecks
- Improve supply chain decision-making

## Key Features
- Star Schema Data Model
- Advanced DAX Measures
- Interactive KPI Cards
- Executive Dashboard
- Logistics Performance Analysis
- Warehouse Insights
- Dynamic Page Titles
- Navigation Buttons
- Bookmarks
- Reset Filters
- Interactive Slicers
- Tooltips

## KPIs
- Total Orders
- Total Shipment Weight
- Total Units Shipped
- Average Transit Time
- On-Time Delivery %
- Late Shipments
- Average Ship Ahead Days

- Power BI
- Power Query
- DAX
- Microsoft Excel
